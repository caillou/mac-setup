# Downloads view writer

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Make Downloads open in list view, Date Added column visible, sorted by Date Added descending, by writing the folder's view record into the parent folder's `.DS_Store`.

- A small Python module: a function that takes the parent store path and writes the `Downloads` record with the three entries from the prototype (`vstl` type `Nlsv`, `vSrn` long 1, `lsvC` blob), where the blob is the binary plist captured from the personal Mac (base64 in the research notes). Creates the store when missing. Read-back function that decodes the blob's sort column.
- A change-triggered shell script that creates a throwaway virtualenv with `ds_store`, runs `killall Finder` first (closes windows so Finder's cache can't overwrite the file), runs the writer, then `killall Finder` again.
- Python unit tests against a temporary store: write, read back, assert the three entries, the decoded `sortColumn == dateAdded`, and that Date Added is visible. Tests run in CI.
- Verified working on macOS 26.6 on both Macs with exactly this procedure.
