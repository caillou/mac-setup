# Bootstrap and verify the new Mac

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Run the one-line bootstrap on the managed Mac and verify the result against the PRD.

- Preconditions: `sudo -v` works for the local account; Command Line Tools already installed there.
- Run the one-liner with built-in git and the source flag; answer the group prompts (personal no, embedded no); watch for the Homebrew sudo prompt and the gh browser login.
- Walk the printed manual checklist: privacy approvals, Azure DevOps key paste, Karabiner first launch, dictation consent.
- Verify: fish prompt and abbreviations; Downloads view; Cmd+N; screenshots; trackpad settings incl. tap to click; Fn keys; natural scroll off; Dock allow-list and appearance; black wallpaper; click on wallpaper does nothing; widgets hidden; dictation double-Control; power settings; iTerm2 profile; git identity in an ICFM clone; asdf versions; Karabiner rules and the Hammerspoon Ctrl+S layout if the apps were provided; auto-brightness off.
- Reboot once and check whether the pointer speed persisted and whether System Settings shows it; record the outcome in the research notes and, if it didn't persist, move pointer speed to the manual checklist.
- Record any Intune-blocked step in the research notes.
