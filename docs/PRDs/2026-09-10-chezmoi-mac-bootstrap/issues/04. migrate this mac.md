# Migrate this Mac

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Make the personal Mac the first machine kept in sync, reviewing every change before it lands. The repo files written by the earlier issues are the source of truth: nothing is adopted from the home directory, which would overwrite them with the stale versions.

- `chezmoi init --source ~/repos/caillou/dotfiles` (answers: managed no, personal yes, embedded yes or no as wanted) so chezmoi knows where the repo is; without it, `chezmoi diff` reads the wrong source.
- iTerm2 fonts: install the `font-anonymice-nerd-font` cask, set the profile's non-ASCII font to `AnonymiceProNerdFontMono-Regular 16` in iTerm2, delete the 2023 `Anonymice Nerd Font Complete Mono.ttf` and the unused `BlexMonoNerdFont-*.ttf` files from `~/Library/Fonts`, confirm the Pure prompt glyphs still render. Then export iTerm2's preferences into `.iterm2/` in the repo.
- Confirm the three Hammerspoon files and the Karabiner source in the repo match the live ones (diff, not adopt).
- Backup: `tar` every target listed by `chezmoi managed` plus `~/.config/fish/fish_variables` into a dated archive outside the repo; chezmoi keeps no backups and the universal-variable purge hits all open fish sessions at once.
- Purge the dead fish universal variables listed in the research notes (BrowserStack, pyenv, Spacefish, colours, init markers); the settings kept already live in the conf.d file from the shell issue. Remove the old `fishfile`. Remove `~/.nvmrc`.
- Apply in two steps, reviewing with the user: `chezmoi diff`, then `chezmoi apply --exclude scripts` (files only: gitconfig with the ICFM override taking effect immediately for `~/repos/icfm`, shell files, Hammerspoon files replacing the `~/.hammerspoon/keyboard` symlink and old `init.lua`); open a new fish and check prompt, abbreviations, `node --version`, Ctrl+S layout; then `chezmoi apply` for the scripts (expect: the display script a true no-op, the defaults script restarting Finder and Dock, one Automation prompt for System Events only if the wallpaper isn't already a colour, sudo prompts for pmset and display).
- asdf: the managed shell files no longer source the git-clone install; keep `~/.asdf` as data dir; after the apply installed Homebrew asdf and ran `asdf reshim`, confirm node and python resolve in a new shell.
- Karabiner: already on "Default profile" (done 2026-09-11). Confirm the build from `.karabiner/` produces rules identical to the current ones. Delete `~/.hammerspoon/Spoons/EmmyLua.spoon` if unwanted.
- Archive `caillou/keyboard` and `caillou/karabiner.ts` on GitHub (`gh repo archive`) after adding a README line pointing at dotfiles; remove `~/repos/keyboard` and `~/repos/caillou/karabiner.ts`.
- Verify afterwards: prompt and abbreviations unchanged, git identity per folder, Downloads view intact, Dock unchanged, Karabiner remaps and Hammerspoon layout work, nothing else visibly different. Rollback is the tar archive.
