## What to build

Replace Apple's default Dock with exactly the allow-list.

- `dockutil` is in the Brewfile core. A change-triggered script removes all persistent apps and adds the allow-list in order: Freeform, iPhone Mirroring, Numbers (system apps live under /System/Applications), skipping entries whose app is absent. Then adds `~/Downloads` to the others section as a stack, fan view, sorted by date added. Restarts the Dock once at the end.
- The allow-list is a template variable or a small data file so adding an app is a one-line change; the script's hash comment includes it so the Dock is rebuilt only when the list changes.
- Dock appearance keys are in the defaults issue, not here.
