## What to build

Make the personal Mac the first machine kept in sync, reviewing every change before it lands. The repo files written by the earlier issues are the source of truth: nothing is adopted from the home directory, which would overwrite them with the stale versions.

- iTerm2 fonts: install the `font-anonymice-nerd-font` cask (arrives with the Brewfile), set the profile's non-ASCII font to `AnonymiceProNerdFontMono-Regular 16` in iTerm2, delete the 2023 `Anonymice Nerd Font Complete Mono.ttf` and the unused `BlexMonoNerdFont-*.ttf` files from `~/Library/Fonts`, confirm the Pure prompt glyphs still render.
- Copy into the repo what only exists on this Mac: the iTerm2 preferences export into `.iterm2/` (after the font change above), and confirm the three Hammerspoon files and the Karabiner source in the repo match the live ones (diff, not adopt).
- Purge the dead fish universal variables listed in the research notes (BrowserStack, pyenv, Spacefish, colours, init markers); the settings kept already live in the conf.d file from the shell issue. Remove the old `fishfile`.
- Retire the git-clone asdf: the managed shell files no longer source it; keep `~/.asdf` as data dir; after the apply installs Homebrew asdf, run `asdf reshim` and confirm node and python resolve. Remove `~/.nvmrc`.
- Replace the `~/.hammerspoon/keyboard` symlink and the old `init.lua` with the managed files (the apply does this; remove the symlink first); confirm Ctrl+S layout works; delete `~/.hammerspoon/Spoons/EmmyLua.spoon` if unwanted.
- Karabiner: already on "Default profile" (done 2026-09-11). Confirm the build from `.karabiner/` produces rules identical to the current ones.
- Run `chezmoi diff`, review with the user, then `chezmoi apply`. Expected: gitconfig change (BKW and Apprentice overrides gone, ICFM override added), shell files, Hammerspoon files, the scripts running once.
- Archive `caillou/keyboard` and `caillou/karabiner.ts` on GitHub (`gh repo archive`) after adding a README line pointing at dotfiles; remove `~/repos/keyboard` and `~/repos/caillou/karabiner.ts`.
- Verify afterwards: prompt and abbreviations unchanged, git identity per folder, Downloads view intact, Dock unchanged, Karabiner remaps and Hammerspoon layout work, nothing else visibly different.
