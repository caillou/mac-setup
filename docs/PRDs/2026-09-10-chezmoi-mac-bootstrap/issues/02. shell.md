## What to build

Make fish, its prompt, plugins and helpers, and the zsh mirror, part of the repo, and register fish as the login shell.

- `config.fish` as a plain file with home-relative paths (`~`, `$HOME`), never a template, so `chezmoi re-add` works. Contents as today: brew shellenv, locale, pager, path additions (drop the non-existent `~/.bin`), completion paths, Docker init guarded on the file existing, all abbreviations, asdf init in the Homebrew asdf form, `~/.local/bin`.
- conf.d: the fish 4.3 frozen theme file (Ayu Dark) managed as-is; a new file with the settings kept from universal variables: exported `XDG_CONFIG_HOME`, `fish_emoji_width 2`, and only the Pure options that differ from Pure's defaults, found by diffing the 73 `pure_*` universal variables against the `_pure_set_default` calls in Pure's `conf.d/pure.fish`. Drop the frozen key-bindings file.
- `functions/karabinerRestart.fish` managed. Plugin-owned functions, conf.d files and completions are not managed.
- `fish_plugins` with `jethrokuan/z`, `pure-fish/pure`, `jethrokuan/fzf` (the file already exists on this Mac with these three; the old `fishfile` is a leftover removed in the migration). `run_after_20-fish-plugins.sh.tmpl`: exit if `hash_unchanged fish-plugins <hash of fish_plugins>` and fisher is installed; else install fisher when absent, run `fisher update`, store the hash on success.
- Login shell script (`run_after_21-login-shell.sh.tmpl`, exits immediately when the login shell is already fish): append the Homebrew fish path to `/etc/shells` when missing (sudo), then `chsh` when the current shell differs; if `chsh` rejects the password (federated Platform SSO accounts), fall back to `sudo dscl . -create /Users/$USER UserShell <fish>`. Guarded so re-runs are no-ops.
- `~/.zprofile`, `~/.zshrc`, `~/.bash_profile`, `~/.bashrc` (without the stray echo), `~/.inputrc` managed as plain files; the asdf line switched to the Homebrew asdf form.
- The universal variables file is never managed; purging its dead entries happens in the migration issue.
