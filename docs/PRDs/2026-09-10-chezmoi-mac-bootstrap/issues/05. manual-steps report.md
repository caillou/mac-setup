## What to build

`run_after_90-report.sh.tmpl` runs on every apply and prints the checklist of what macOS won't let a script do, tailored to the machine, from the marker files in `~/.local/state/dotfiles/`.

- Always: Privacy & Security approvals for Karabiner and Hammerspoon (Input Monitoring, Accessibility, driver extension) when those apps exist; Karabiner first launch so its default profile and config file exist; first dictation activation and language model downloads; verify pointer speed and auto-brightness in System Settings.
- When `ssh-key-generated` is marked: paste the public key into Azure DevOps, with the key printed again; the marker is cleared once the user confirms (documented in the README) or left until then.
- Unmanaged: when `appstore-signin-needed` is marked, sign in to the App Store and re-run apply.
- Managed: the list of allow-listed apps missing from /Applications to request via Self Service.
- Items whose markers exist (`pointer-speed-applied`, `auto-brightness-applied`) are omitted, so the list shrinks on re-runs.
