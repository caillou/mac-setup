## What to build

The last script of the apply prints the checklist of what macOS won't let a script do, tailored to the machine.

- Always: Privacy & Security approvals for Karabiner and Hammerspoon (Input Monitoring, Accessibility, driver extension) when those apps exist; Karabiner first launch so the profile exists; first dictation activation and language model downloads; verify pointer speed and display settings in System Settings.
- When the ssh key was just generated: paste the public key into Azure DevOps, with the key printed again.
- Unmanaged: sign in to the App Store before App Store apps install (re-run apply afterwards).
- Managed: the list of allow-listed apps missing from /Applications to request via Self Service.
- Items whose scripts reported success are omitted, so the list shrinks on re-runs.
