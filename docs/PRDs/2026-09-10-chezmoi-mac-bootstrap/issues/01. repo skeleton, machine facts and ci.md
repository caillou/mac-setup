# Repo skeleton, machine facts and CI

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Turn this repo into a chezmoi source directory with the scaffolding every later issue plugs into.

- chezmoi config template: detects MDM enrollment with `profiles status -type enrollment` into a `managed` boolean that the user can override in the generated config; prompts once (`promptBoolOnce`) for the group flags `personal` and `embedded`; pins `sourceDir` to `~/repos/caillou/dotfiles` so commands after the bootstrap need no `--source` flag.
- Machine-facts shell library, POSIX sh, sourced by scripts: `is_managed`, `app_present <App name>` (bundle in /Applications), `has_command`, `default_is <domain> <key> <value>`. Pure functions, no side effects, the only place these checks exist.
- Script layout and numbering convention for `.chezmoiscripts`: run-once "before" scripts first (Homebrew), then change-triggered scripts in the PRD order: packages, shell, git and ssh, asdf, keyboard projects, defaults, Dock, Downloads view, iTerm2, display, report. Every script starts with a shebang and is guarded to macOS.
- A `.chezmoiignore` that excludes repo-only files (docs, tests, CI, README) from the home directory.
- Test harness: bats for the facts library with stubbed `profiles`, `ls` and `command`; shellcheck for every script; lefthook running both before commit, modelled on the keyboard repo.
- GitHub Actions job on a macOS runner: install chezmoi, `chezmoi init` from the checkout with fake config data, `chezmoi apply --dry-run --verbose`. Fails on template errors and script ordering mistakes.
- The old README content and the 2023 `macos` script stay in place for now; later issues replace them.

## Acceptance criteria

- [ ] `chezmoi init --source <checkout>` on a clean HOME renders a config with `managed`, `personal`, `embedded` and `sourceDir` set
- [ ] `managed` is true when the enrollment command reports MDM enrollment and false otherwise; an override in the config wins
- [ ] bats tests cover managed and unmanaged, app present and absent, command present and absent, key at value and not
- [ ] shellcheck passes on every script; lefthook runs bats and shellcheck before commit
- [ ] the GitHub Actions macOS job passes with a dry-run apply on a fresh runner
- [ ] `chezmoi managed` lists no repo-only files
