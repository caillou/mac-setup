# macOS defaults script

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

One change-triggered POSIX sh script that applies every macOS setting in the PRD's defaults section, using the values in the research notes.

- Sequence: quit System Settings; write all keys; run `activateSettings -u` (private, as the logged-in user) so input settings apply without logout; `killall Finder Dock SystemUIServer`.
- Keyboard: standard function keys, Fn alone does nothing, key repeat and initial repeat, press-and-hold off, full keyboard access, the four text substitutions off.
- Scrolling: natural scrolling off, swipe between pages off.
- Trackpad: all keys from the notes, written to the built-in and Bluetooth trackpad domains plus the global and per-host copies of tap-to-click and secondary click. Pointer speed 0.6875 for trackpad and mouse, then read back through `hidutil` and print a warning when the live value didn't change. Double-click speed is not set.
- Screenshots: Downloads, PNG, no thumbnail.
- Finder: new window opens Downloads (`PfLo` plus path), extensions, status bar, folders first, no extension warning, no .DS_Store on network and USB volumes, drive visibility on the Desktop, expanded save and print panels, save to disk, and the Desktop icon view dictionary (arranged by kind, icon size 16, grid 100, text 14, label right).
- Window manager: click wallpaper to show desktop only in Stage Manager, desktop items hidden, widgets hidden on the Desktop.
- Dock appearance: autohide with 0.5 s delay, tile size 16, magnification to 128, bottom, no recents, no launch animation, four hot corners off. Dock contents are a separate issue.
- Wallpaper: System Events sets every desktop to the black solid-colour image that ships with macOS; written unconditionally because a system colour can't be read back.
- Dictation: enabled, symbolic hotkey 164 as captured (press Control twice), preferred languages en_US, fr_CH, de_CH.
- Power via `sudo pmset`: on adapter never sleep, display sleep 10; on battery display sleep 15, no dimming. Compare before writing so re-runs don't prompt for nothing.
- Not included: Safari, Messages, quarantine, accessibility zoom, locale.
- Render tests: chezmoi renders the script with fake data and the tests assert the expected `defaults write` lines and the ordering (settings quit first, activateSettings before the killalls).
