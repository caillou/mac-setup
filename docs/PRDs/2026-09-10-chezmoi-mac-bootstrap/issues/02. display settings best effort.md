## What to build

Turn off True Tone and auto-brightness where a script can, and say so where it can't.

- First, one sudo read on the personal Mac of root's CoreBrightness preferences to confirm both are off there and to learn the exact key names and the per-user, per-display nesting. This needs the user at the keyboard.
- A change-triggered sudo script: read the plist on the target machine, locate the built-in display entry, set both flags off, restart `corebrightnessd`, read back. If the value didn't hold, print the manual instruction (Displays settings) and exit zero.
- Never fail the apply because of this module.
