## What to build

Language runtimes through Homebrew asdf.

- `asdf` is in the Brewfile core. Managed `~/.asdfrc` with legacy version files enabled and `~/.tool-versions` pinning nodejs and python to the versions in use (node 24.15.0, python 3.12.13; confirm at implementation).
- `run_onchange_after_40-asdf.sh.tmpl`, hashed on the tool-versions file: add the nodejs and python plugins when missing, `asdf install` for the pinned versions. Never `asdf set`: `~/.tool-versions` is managed and would drift. `asdf reshim` at the end.
- Shell init in fish and zprofile is the Homebrew asdf form (shims on PATH, completions), done in the shell issue; this issue verifies it.
- The data directory stays `~/.asdf` so existing installs on the personal Mac are reused after the git-clone install is retired in the migration issue. The stray `~/.nvmrc` in the home folder (currently a different node version) is removed there too.
