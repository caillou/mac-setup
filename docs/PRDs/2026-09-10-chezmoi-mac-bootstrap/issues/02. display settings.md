## What to build

Turn auto-brightness off for every display. True Tone stays at its default.

- Auto-brightness lives in root's CoreBrightness preferences under `DisplayPreferences`, one dict per display identifier, key `AutoBrightnessEnable` (confirmed false on the personal Mac; see notes for the read command).
- `run_onchange_after_64-display.sh.tmpl`, sudo: `sudo defaults export com.apple.CoreBrightness -` (root's domain, via `sudo`), edit with `plutil`/python to set `AutoBrightnessEnable` false on every entry under `DisplayPreferences` (iterate; identifiers differ per machine), `sudo defaults import` it back, `sudo killall corebrightnessd`, read back. Never edit the plist file directly; cfprefsd's cache would clobber it. Reading needs sudo too, so one prompt per run is accepted. Mark `auto-brightness-applied` on success; if any entry still reads true, print the manual instruction (System Settings, Displays) and exit zero.
- True Tone has no key in that file when untouched, and the personal Mac never touched it, so nothing is written for it.
- Never fail the apply because of this module.
