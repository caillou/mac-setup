## What to build

Turn auto-brightness off for every display. True Tone stays at its default.

- Auto-brightness lives in root's CoreBrightness preferences under `DisplayPreferences`, one dict per display identifier, key `AutoBrightnessEnable` (confirmed false on the personal Mac; see notes for the read command).
- `run_after_64-display.sh.tmpl`, every apply, sudo: `sudo -H defaults export com.apple.CoreBrightness -` (root's domain), edit with python plistlib to set `AutoBrightnessEnable` false on every entry under `DisplayPreferences` (iterate; identifiers differ per machine). If nothing changed, exit silently with no daemon restart (true no-op on the personal Mac, where every entry is already false). Else `sudo -H defaults import com.apple.CoreBrightness -`, `sudo killall corebrightnessd`, read back. Never edit the plist file directly; cfprefsd's cache would clobber it. Reading needs sudo, so one prompt per apply is accepted. `mark auto-brightness-applied` on success; if any entry still reads true, print the manual instruction (System Settings, Displays) and exit zero.
- True Tone has no key in that file when untouched, and the personal Mac never touched it, so nothing is written for it.
- Never fail the apply because of this module.
