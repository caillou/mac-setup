## What to build

Keep iTerm2's profile, font and colours in the repo, syncing both ways.

- A folder in the repo for iTerm2 preferences; migration (later issue) exports the current `com.googlecode.iterm2.plist` into it. The old `ayu dark.itermcolors` moves there as reference.
- A change-triggered script or defaults lines that set `PrefsCustomFolder` to that folder (home-relative, so this file is a template), `LoadPrefsFromCustomFolder` true, and the "save changes automatically" selection, guarded on iTerm2 being installed.
- Document that iTerm2 writes back on quit, so changes made in iTerm2 appear as repo drift to commit.
