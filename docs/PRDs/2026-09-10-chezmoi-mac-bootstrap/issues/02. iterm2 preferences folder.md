## What to build

Keep iTerm2's profile, font and colours in the repo, syncing both ways.

- A dot-prefixed folder `.iterm2/` in the chezmoi source directory (ignored as a target by chezmoi, so iTerm2 can write into the repo directly); migration (later issue) exports the current `com.googlecode.iterm2.plist` into it. The old `ayu dark.itermcolors` moves there as reference.
- `run_onchange_after_63-iterm2.sh.tmpl` sets `PrefsCustomFolder` to `{{ .chezmoi.sourceDir }}/.iterm2`, `LoadPrefsFromCustomFolder` true, and `NoSyncNeverRemindPrefsChangesLostForFile_selection` 2 (save automatically), guarded on iTerm2 being installed and compared before writing.
- Document that iTerm2 writes back on quit, so changes made in iTerm2 appear as repo drift to commit.
