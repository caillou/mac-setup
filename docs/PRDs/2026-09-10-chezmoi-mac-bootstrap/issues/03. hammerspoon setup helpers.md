# Hammerspoon setup helpers

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

A fourth Lua file, `setup.lua`, with machine-setup helpers that scripts call through the `hs` command line when Hammerspoon is running and has Accessibility.

- `setup.wallpaper(path)`: sets the desktop image on every screen via Hammerspoon's desktop-image API. Used by the defaults script for the black solid-colour image, replacing the System Events call and its Automation prompt.
- `setup.notify(text)`: shows a status overlay using the status-message module, so setup scripts can report on screen.
- Loaded on demand (`hs -A -c 'require("setup").wallpaper("...")'`, with the no-autolaunch flag), not at startup. The facts include's `hs_available` (Hammerspoon running per `pgrep -x Hammerspoon` and `hs` on PATH) gates every call, so a machine without Hammerspoon never gets a launch dialog and callers fall back to their non-Hammerspoon path. On a fresh Mac Hammerspoon has not run during the first apply, so the fallback is what the bootstrap uses; the helper matters on re-syncs.
- Candidates, not built now: driving the Trackpad pane's tracking slider and the Keyboard pane's dictation switch through the accessibility API.
