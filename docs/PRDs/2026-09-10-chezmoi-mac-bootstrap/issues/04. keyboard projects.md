## What to build

Wire in the karabiner.ts and keyboard repos without vendoring them.

- Run-once script: clone `caillou/karabiner.ts` and `caillou/keyboard` over ssh into `~/repos/caillou` when absent (`mkdir -p` the parent).
- Change-triggered script, guarded on the app bundles being present: in karabiner.ts run `npm install` and `npm run build` (needs node from asdf); in keyboard run `make install`, which handles its own Homebrew deps, the Hammerspoon symlink and relaunch. Hash on a marker file so it re-runs when the user asks, not on every apply; document `git pull` in those repos as the update path.
- Karabiner needs its `caillou` profile to exist before the build writes it; the manual checklist covers first launch. The generated `karabiner.json` is not in the repo. `~/.hammerspoon/Spoons` is never managed.
- On a managed Mac without Karabiner or Hammerspoon the scripts print what they skipped and exit zero.
