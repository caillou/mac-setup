# ssh key upload runs once

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Upload the public key to GitHub once, not on every apply.

- The defect, from the final right-thing review: `.chezmoiscripts/run_after_30-github-and-ssh.sh.tmpl:94-99` POSTs the key on every apply. `gh ssh-key add` is idempotent, so the call is harmless online, but offline it fails and the script prints `github-and-ssh: uploading ... failed: ...` and stops. It is the only network call left on the settled path, and it contradicts the script's own header ("a machine that is already set up runs this script in silence") and story 45.
- Fix: a marker, `ssh-key-uploaded`, holding the public key path, written with the preamble's existing helpers (`mark`, `marked`, `marker_value` in `.chezmoitemplates/facts.sh:56-75`, the same shape as `ssh-key-generated`). Skip the upload when the stored value equals `$KEY.pub`; a different path (a new key) uploads again. The review's alternative, comparing the key fingerprint against `gh ssh-key list`, is another network call on the settled path, so the marker wins.
- Write the marker only after an exit-0 upload. The failure path stays as it is: print the failure, exit 0, no marker, so the next apply tries again.
- `run_after_90-report.sh.tmpl` must not change. It reads `ssh-key-generated` for the Azure DevOps paste; the new marker is internal to script 30 and never reaches the checklist.

## Acceptance criteria

- [ ] a second apply with the marker present calls neither `gh ssh-key add` (the gh stub log has no `ssh-key add` line) nor prints a failure, and the script output is empty
- [ ] a fresh machine uploads once and `$STATE/ssh-key-uploaded` holds the public key path
- [ ] a failed upload leaves no marker, prints the failure, exits 0, and the next run retries
- [ ] a marker holding a different key path uploads again
- [ ] `run_after_90-report.sh.tmpl` and `tests/report.bats` are untouched and `bats tests` is green
